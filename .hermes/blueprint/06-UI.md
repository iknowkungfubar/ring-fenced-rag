# UI/UX Specification

## User Interfaces

RFR ships with four interfaces, each serving a different user type:

| Interface | Audience | Technology | Purpose |
|-----------|----------|------------|---------|
| Web UI | All users | React SPA | Rich query, document browser, settings |
| CLI | Operators/Devs | click + rich | Scriptable, quick queries, setup |
| TUI | Power users | textual | Full management without a browser |
| API | Integrators | REST JSON | Slack bots, CI pipelines, custom tools |

---

## Interface 1: Web UI

### Screen Map

```
/                  → Dashboard (query interface)
/settings          → Settings (API keys, roles, LLM config)
/documents         → Document browser
/documents/:id     → Single document detail
/ingest            → Trigger ingestion
/ingest/:task_id   → Ingestion progress
/login             → API key entry (gate)
```

**Purpose:** Enter API key to access the web UI. Keys are stored in localStorage.

## Interface 2: CLI

### Command Tree

```
rfr
├── init                         — Create config file + docker-compose.yml
├── up [-d] [--gpu rocm|cuda]    — Start all Docker services
├── down                         — Stop all Docker services
├── restart [service]            — Restart specific or all services
├── status                       — Show health of all components
├── logs [service] [-f]          — Tail logs for a service
├── config
│   ├── show                     — Print resolved config
│   └── set <key> <value>        — Update a config value
├── ingest [path]                 — Ingest docs from path
│   └── --role <role>            — Default role assignment
├── query "question"              — Ask a question
│   ├── --role <role>            — Override role for this query
│   ├── --top-k <n>              — Number of documents to retrieve
│   └── --no-llm                 — Return retrieved docs only (no generation)
├── keys
│   ├── create <name>            — Create new API key
│   │   └── --role <role>        — Role for this key
│   └── list                     — List existing keys
│   └── revoke <prefix>          — Deactivate a key
├── docs
│   ├── list                     — List indexed documents
│   └── delete <doc_id>          — Delete a document
├── standalone                   — Start API server without Docker
│   └── --port 8000
└── tui                          — Launch full-screen TUI
```

### CLI Example Session

```bash
# Install
pip install ring-fenced-rag

# Initialize project
cd my-docs
rfr init

# Start the stack
rfr up

# Ingest some docs
rfr ingest ./manuals/ --role senior_engineer

# Ask a question
rfr query "How do I restart Nginx?"
> To restart the Nginx server, execute `systemctl restart nginx`...

# Create API key for the web UI
rfr keys create web-access --role senior_engineer
> Created key: rfr_a1b2c3d4e5f6... (shown once)
```

## Design System

### Colors (Dark Mode Default — matches security-focused aesthetic)

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-primary` | `#0f1117` | Page background |
| `--bg-secondary` | `#1a1d27` | Card/panel background |
| `--bg-tertiary` | `#252836` | Input backgrounds |
| `--accent` | `#4f8cff` | Primary actions, links |
| `--accent-dim` | `#2a5bcc` | Hover states |
| `--text-primary` | `#e4e6ed` | Body text |
| `--text-secondary` | `#8b8fa3` | Muted text |
| `--success` | `#22c55e` | Healthy status |
| `--warning` | `#f59e0b` | Degraded status |
| `--error` | `#ef4444` | Error states |
| `--border` | `#2e3144` | Borders |

### Typography
- System font stack: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", monospace`
- Mono for code blocks: `JetBrains Mono, Fira Code, monospace`

### Responsive Breakpoints
- Mobile: < 640px — single column, hamburger menu
- Tablet: 640-1024px — two column layout
- Desktop: > 1024px — full three-section layout

### Accessibility
- All interactive elements focusable via keyboard
- ARIA labels on icon-only controls
- Color contrast ratios ≥ 4.5:1 for text
- Reduced motion media query support
- Error messages linked to inputs via `aria-describedby`
